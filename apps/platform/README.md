# Platform Applications

This directory contains Argo CD child Applications managed by the `inenp-platform-root` root Application.

Gate 3 adds platform operators here in separate pull requests so ownership stays visible:

- cert-manager and ACME issuers
- External Secrets Operator
- CloudNativePG
- ExternalDNS
- ClusterSecretStore
- Crossplane providers

Current child Applications:

- `cert-manager`
- `external-secrets`
- `cloudnative-pg`
- `external-dns`
- `cluster-secret-store`
- `crossplane`
- `crossplane-providers`
